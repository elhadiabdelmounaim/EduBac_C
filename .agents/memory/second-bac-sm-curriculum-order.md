name: 2ème Bac SM curriculum order
description: Source and ordering rationale for the French 2ème Bac Sciences Mathématiques curriculum.
---

Use the shared, numbered chapter sequence shown on AlloSchool's Sciences Mathématiques A and B BIOF pages. Prof Salmi and Moutamadris present the same subject matter as course sections in a different order, splitting out the TAF, complex-number parts, and primitives/integral calculus. Do not combine those section headings into the numbered chapter list.

**Why:** The numbered A/B program is the clearest common curriculum index; the other pages reflect a different teaching/resource sequence.

**How to apply:** When adjusting the French 2ème Bac SM catalog, preserve the shared A/B chapter order unless the user asks for a variant-specific sequence.
