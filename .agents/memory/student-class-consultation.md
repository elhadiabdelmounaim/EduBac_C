---
name: Student class page and consultation
description: User requirements for the student's Ma classe page and professor contact.
---

On a student's « Ma classe » page, show only the level, date joined, active/inactive state, class code, and a French « Consulter le professeur » button. The button opens a private one-to-one conversation with that class's teacher, not the group chat. The consultation should support text, emoji, image/file/audio attachments, voice recording, playback, and visible read receipts.

**Why:** The user explicitly requested a minimal class-information view and a one-to-one chat with familiar messaging controls.

**How to apply:** Keep teacher-only class management and student lists out of this page. Enforce conversation and attachment access for only the class's student and assigned teacher; keep private uploads outside publicly served media, and preserve the existing group chat separately.
