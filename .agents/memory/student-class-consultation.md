---
name: Student class page and consultation
description: User requirements for the student's Ma classe page and professor contact.
---

On a student's « Ma classe » page, show only the level, date joined, active/inactive state, class code, and a French « Consulter le professeur » button. The button opens a private one-to-one conversation with that class's teacher, not the group chat.

**Why:** The user explicitly requested a minimal class-information view and an individual consultation channel.

**How to apply:** Keep teacher-only class management and student lists out of this page. Enforce conversation access for only the class's student and assigned teacher, and preserve the existing group chat separately.
