تقرير توحيد أسماء مجلدات المستويات — EduBac

1. المجلدات المعاد تسميتها داخل EduBac/media/lessons

tc   → TCS
1sc  → 1BAC_SE
1let → 1BAC_L
1sm  → 1BAC_SM
2svt → 2BAC_SVT
2pc  → 2BAC_PC
2let → 2BAC_L
2sm  → 2BAC_SM

أضيف المجلدان TCL وTCT فارغين، باستثناء .gitkeep، وفق الاختيار المؤكد.
لم تنشأ برامج أو دروس جديدة للآداب أو التكنولوجيا، ولم تنسخ الدروس المشتركة.
يظل ربط برنامج الجذع المشترك الحالي كما كان قبل التغيير.
لم تتغير أسماء الفصول أو ملفات الدروس والتمارين وPDF وTXT.

2. تحديث المراجع

EduBac/education/media_library.py:
اعتماد جدول موحد للاختصارات، يستخدم لاكتشاف PDF ومصادر TXT.

EduBac/education/models.py:
استخدام الجدول نفسه في تحميل ملفات Markdown وPDF القديمة.

EduBac/education/management/commands/load_curriculum.py:
استخدام الاختصارات الجديدة، وربط PDF الموجود في مكانه بدلاً من نسخه.

EduBac/education/management/commands/organize_media.py:
استخدام المسارات الجديدة وإنشاء TCL وTCT دون اختراع محتوى.

EduBac/education/management/commands/normalize_level_folders.py:
أمر آمن لإعادة التسمية، يدعم --dry-run، ويرفض تعارض الوجهات.
يحدّث مراجع FileField التي تشير إلى الملفات المنقولة، مع الحفاظ على معرّفات السجلات.
في قاعدة البيانات الحالية لم توجد مراجع ملفات قديمة تتطلب التعديل.

حُدّثت اختبارات المجلدات، وأضيفت اختبارات النقل والمحاكاة والتعارض والتراجع عن نقل فاشل.
حُدّث توقعان قديمان في اختبارات صفحة إنشاء الاختبارات ليتوافقا مع سلوكها الحالي.
لم تتطلب قوالب HTML أو JavaScript أو CSS أو إعدادات الخادم تغييرًا لهذا التوحيد.

3. الأسماء المحفوظة عمدًا

معرّفات المستويات الداخلية مثل tronc_commun و1ere_bac_lettres بقيت كما هي.
لم تتغير حسابات المستخدمين أو معرّفات الدروس أو روابط الصفحات أو أسماء المستويات المعروضة.
توجد اختصارات المجلدات القديمة فقط في أمر التوافق واختبارات نقل الملفات القديمة.
مجلدات مثل media/results/classes/classe_1bac_1 تمثل صفوفًا ونتائج، لا مجلدات مستويات؛ لم تُغيّر.
لم تُعدّل ملفات migrations أو بنية قاعدة البيانات.

4. التحقق

تمت مقارنة بصمات SHA-256 للملفات الـ275 الموجودة قبل النقل:
جميع الملفات موجودة في المسارات الجديدة، ومحتواها مطابق تمامًا.
يشمل ذلك logique.pdf وlogique.txt.

نجح 144 اختبارًا تغطي education وai وaccounts وquizzes،
من ضمنها أربعة مسارات متصفح لاختيار الدروس والمصادر وتوليد الاختبارات.
كانت استجابات الذكاء الاصطناعي في الاختبارات محاكاة، دون استدعاءات حقيقية مدفوعة.
لا يمثل هذا نجاح جميع اختبارات المتصفح الأخرى في المشروع.

نجح فحص Django، وأكد makemigrations --check --dry-run عدم وجود تغييرات في المخطط.
إعادة تشغيل أمر المحاكاة بعد النقل أعطت صفر مجلدات وصفر مراجع متبقية لإعادة التسمية.
بعد إعادة تشغيل الخادم، استجابت الصفحة الرئيسية وصفحة المستوى وروابط فتح PDF وتنزيله بـ HTTP 200.
تمت مقارنة الملف المفتوح والمنزّل مع PDF الأصلي وتطابق المحتوى بالكامل.
تمت قراءة logique.txt عبر سياق الذكاء الاصطناعي من مجلده الجديد، وفحص صفحة الدرس بصريًا على الهاتف.
استمرت قاعدة البيانات في احتواء المستويات الثمانية والدروس الـ91 والحسابات وبيانات الاختبارات السابقة.
بقيت ملاحظة favicon.ico المفقود، ولا تمنع عرض الصفحات أو فتح الملفات.

5. العمليات اليدوية

لا يلزم نقل إضافي في نسخة العمل الحالية.
لن تنفذ هذه التغييرات تلقائيًا على نسخة أخرى من المشروع تحتوي على المجلدات القديمة.
في تلك النسخة، أوقف الخادم مؤقتًا، ثم نفذ من جذر المشروع:

python EduBac/manage.py normalize_level_folders --dry-run
python EduBac/manage.py normalize_level_folders
python EduBac/manage.py organize_media

ثم شغّل الخادم مجددًا.
إذا وجد تعارض بين مجلد قديم ووجهته الجديدة، يرفض الأمر التنفيذ دون دمج أو استبدال.
لم يُنفذ نشر أو إرسال إلى GitHub.
قواعد تجاهل PDF في Git لم تتغير؛ يجب توفير تلك الملفات منفصلة عند نقل المشروع إلى بيئة أخرى.
