1. Accès

Les cours publics sont accessibles à tous. Les quiz, la messagerie et le tableau blanc sont réservés aux élèves inscrits avec le code de leur classe et dont l’inscription a été validée par le professeur.

2. Compte

  • Le compte est personnel : ne communiquez pas votre mot de passe.
  • Choisissez un nom d’utilisateur correct, sans moquerie ni contenu offensant.
  • En cas d’oubli du mot de passe, le professeur peut le réinitialiser.

3. Messagerie et tableau blanc

  • Les échanges servent au travail scolaire. Restez poli et bienveillant.
  • Sont interdits : insultes, harcèlement, contenus violents ou choquants, publicité, partage de données personnelles d’autrui.
  • Les messages peuvent être signalés ; le professeur peut masquer un message ou suspendre l’accès à la messagerie.

4. Quiz et travail personnel

Les quiz servent à s’entraîner et à mesurer sa progression. Répondez seul : les résultats aident le professeur à adapter son enseignement.

5. Contenus

Les contenus sont fournis pour l’apprentissage. Malgré le soin apporté, une erreur peut subsister : signalez-la au professeur. Les règles de réutilisation figurent dans les mentions légales.

6. Disponibilité

Le site peut être interrompu pour maintenance. L’éditeur fait de son mieux pour assurer sa disponibilité, sans garantie.

7. Données personnelles

Voir la politique de confidentialité.
