Comment m’inscrire ?
  1. Demandez le code de classe à votre professeur.
  2. Ouvrez Inscription, remplissez le formulaire avec ce code.
  3. Le professeur valide votre demande : vous pouvez ensuite vous connecter avec votre nom d’utilisateur.

Guide illustré en arabe (inscription et connexion), à imprimer

Installer EduBac sur mon téléphone

Android (Chrome) : menu → « Installer l’application » (ou « Ajouter à l’écran d’accueil »). L’icône EduBac apparaît avec vos applications.

iPhone (Safari) : bouton Partager → « Sur l’écran d’accueil » → « Ajouter ». Ouvrez ensuite EduBac depuis cette icône.

Recevoir les notifications sur le téléphone
  1. Ouvrez EduBac (sur iPhone : depuis l’icône installée, iOS 16.4 ou plus récent).
  2. Appuyez sur la cloche , puis sur Activer, et acceptez.
  3. Vérifiez dans Préférences de notification avec « Envoyer un test ».

Rien ne s’affiche ? Autorisez les notifications pour Chrome (ou EduBac) dans les réglages du téléphone, et désactivez le mode « Ne pas déranger ».

Passer un quiz
  • Les quiz envoyés par le professeur apparaissent dans Mes quiz et sur le tableau de bord, avec leur date limite.
  • Chaque question a un temps limité : lisez bien avant de répondre.
  • Après l’envoi, vous voyez votre note et la correction.
Écrire au professeur

Ouvrez Messagerie : la discussion de classe est visible par toute la classe ; une consultation est un échange privé avec le professeur. Vous pouvez joindre une photo de votre exercice ou envoyer un message vocal. Pour écrire une formule : $x^2$.

Le tableau blanc

Quand le professeur partage un tableau, une notification vous l’indique. Selon ses réglages, vous pouvez regarder, lever la main ou dessiner quand il vous donne la parole.

Mot de passe oublié

Demandez à votre professeur : il peut réinitialiser votre mot de passe. Votre compte et vos résultats sont conservés. Après 8 essais incorrects, la connexion est bloquée 15 minutes par sécurité.

Mode sombre

Le bouton lune en haut de la page change le thème ; votre choix est mémorisé sur l’appareil.
