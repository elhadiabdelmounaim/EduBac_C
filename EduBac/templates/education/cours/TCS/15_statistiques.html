IVocabulaire statistique

Définition
  • La population est l'ensemble étudié ; chacun de ses éléments est un individu.
  • Le caractère (ou variable statistique) est la propriété étudiée. Il est qualitatif s'il n'est pas mesurable (situation familiale, couleur…) et quantitatif s'il est mesurable ; un caractère quantitatif est discret s'il prend des valeurs isolées (notes, nombre d'enfants) et continu s'il prend ses valeurs dans des intervalles appelés classes (taille, vitesse).
  • L'effectif \(n_i\) d'une valeur \(x_i\) est le nombre d'individus correspondant à cette valeur ; l'effectif total est \(N=n_1+n_2+\dots+n_p\).
  • La fréquence de \(x_i\) est \(f_i=\dfrac{n_i}N\) ; on a \(f_1+f_2+\dots+f_p=1\). En pourcentage : \(p_i=100\,f_i\).
  • L'effectif cumulé croissant \(N_i\) de \(x_i\) est la somme des effectifs des valeurs inférieures ou égales à \(x_i\).
Exemples

Les notes obtenues par \(20\) élèves d'une classe de tronc commun à un devoir sont :

Note \(x_i\)\(7\)\(8\)\(10\)\(11\)\(12\)\(14\)\(16\)
Effectif \(n_i\)\(1\)\(2\)\(3\)\(5\)\(4\)\(3\)\(2\)
Effectif cumulé \(N_i\)\(1\)\(3\)\(6\)\(11\)\(15\)\(18\)\(20\)
Fréquence \(f_i\)\(0{,}05\)\(0{,}10\)\(0{,}15\)\(0{,}25\)\(0{,}20\)\(0{,}15\)\(0{,}10\)
Pourcentage \(p_i\)\(5\,\%\)\(10\,\%\)\(15\,\%\)\(25\,\%\)\(20\,\%\)\(15\,\%\)\(10\,\%\)

La population est l'ensemble des \(20\) élèves ; le caractère « note » est quantitatif discret. Le nombre d'élèves ayant une note inférieure ou égale à \(12\) est \(N_5=15\).

IIIParamètres de position

Définition

Soit une série statistique de valeurs \(x_1,\dots,x_p\) d'effectifs \(n_1,\dots,n_p\) et d'effectif total \(N\).

  • Le mode est la valeur de plus grand effectif ; pour une série en classes, on parle de classe modale.
  • La moyenne arithmétique est : \(\overline{x}=\dfrac{n_1x_1+n_2x_2+\dots+n_px_p}N=\dfrac1N\displaystyle\sum_{i=1}^pn_ix_i=\sum_{i=1}^pf_ix_i\).
    Pour une série en classes, \(x_i\) désigne le centre de la classe.
  • La médiane \(Me\) est la valeur qui partage la série ordonnée en deux parties de même effectif.
Méthode — Déterminer la médiane
  • Série discrète : on range les valeurs dans l'ordre croissant. Si \(N\) est impair, \(Me\) est la valeur de rang \(\frac{N+1}2\) ; si \(N\) est pair, \(Me\) est la moyenne des valeurs de rangs \(\frac N2\) et \(\frac N2+1\). On utilise les effectifs cumulés pour repérer ces rangs.
  • Série en classes : on repère la classe \([a;b[\) où l'effectif cumulé atteint \(\frac N2\), puis on fait une interpolation linéaire (lecture sur la courbe des effectifs cumulés) : \(Me=a+(b-a)\times\dfrac{\frac N2-N_{a}}{n}\), où \(N_a\) est l'effectif cumulé avant la classe et \(n\) l'effectif de la classe.
Exemples
  • Notes : le mode est \(11\) ; \(\overline{x}=\dfrac{7+16+30+55+48+42+32}{20}=\dfrac{230}{20}=11{,}5\). \(N=20\) : les valeurs de rangs \(10\) et \(11\) valent toutes deux \(11\) (car \(N_3=6<10\) et \(N_4=11\)), donc \(Me=11\).
  • Tailles : classe modale \([164;168[\) ; centres \(162\), \(166\), \(170\), \(174\) : \[ \overline{x}=\frac{8\times162+14\times166+12\times170+6\times174}{40}=\frac{6704}{40}=167{,}6\ \text{cm}. \] Effectifs cumulés : \(8\), \(22\), \(34\), \(40\) ; \(\frac N2=20\) est atteint dans \([164;168[\) : \(Me=164+4\times\dfrac{20-8}{14}\approx167{,}4\) cm.

IVParamètres de dispersion

Activité 1

Deux classes ont obtenu les notes suivantes :

Classe A : note\(9\)\(10\)\(11\)
Effectif\(3\)\(4\)\(3\)
Classe B : note\(6\)\(8\)\(10\)\(12\)\(14\)
Effectif\(2\)\(2\)\(2\)\(2\)\(2\)

Montrer que les deux classes ont la même moyenne. Les deux séries sont-elles pour autant semblables ?

Définition
  • L'étendue est la différence entre la plus grande et la plus petite valeur.
  • L'écart moyen est : \(e=\dfrac1N\displaystyle\sum_{i=1}^pn_i\,|x_i-\overline{x}|\).
  • La variance est : \(V=\dfrac1N\displaystyle\sum_{i=1}^pn_i\,(x_i-\overline{x})^2=\dfrac1N\displaystyle\sum_{i=1}^pn_ix_i^2-\overline{x}^{\,2}\).
  • L'écart-type est : \(\sigma=\sqrt V\).

Plus ces paramètres sont grands, plus les valeurs sont dispersées autour de la moyenne.

Exemples

Dans l'activité, les deux moyennes valent \(10\).

  • Classe A : étendue \(2\) ; \(e=\dfrac{3\times1+4\times0+3\times1}{10}=0{,}6\) ; \(V=\dfrac{3\times1+3\times1}{10}=0{,}6\) ; \(\sigma\approx0{,}77\).
  • Classe B : étendue \(8\) ; \(e=\dfrac{2(4+2+0+2+4)}{10}=2{,}4\) ; \(V=\dfrac{2(16+4+0+4+16)}{10}=8\) ; \(\sigma=2\sqrt2\approx2{,}83\).

Les notes de la classe B sont beaucoup plus dispersées que celles de la classe A.

Méthode — Organiser le calcul dans un tableau

On ajoute au tableau les lignes \(n_ix_i\), \(|x_i-\overline{x}|\), \(n_i|x_i-\overline{x}|\) et \(n_ix_i^2\), puis on fait la somme de chaque ligne.

Exemples

Nombre d'enfants dans \(30\) familles :

\(x_i\)\(0\)\(1\)\(2\)\(3\)\(4\)Total
\(n_i\)\(4\)\(6\)\(10\)\(6\)\(4\)\(30\)
\(n_ix_i\)\(0\)\(6\)\(20\)\(18\)\(16\)\(60\)
\(n_i|x_i-\overline{x}|\)\(8\)\(6\)\(0\)\(6\)\(8\)\(28\)
\(n_ix_i^2\)\(0\)\(6\)\(40\)\(54\)\(64\)\(164\)

\(\overline{x}=\dfrac{60}{30}=2\) ; \(e=\dfrac{28}{30}\approx0{,}93\) ; \(V=\dfrac{164}{30}-2^2=\dfrac{22}{15}\approx1{,}47\) ; \(\sigma=\sqrt{\dfrac{22}{15}}\approx1{,}21\).
